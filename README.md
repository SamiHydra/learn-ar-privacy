# Learn AR privacy policy

Public privacy-policy webpage for Learn AR, published through GitHub Pages.

- `index.html` contains the complete policy.
- `style.css` provides responsive screen and print formatting.
- `.nojekyll` serves these files directly, without a Jekyll build.

There is no JavaScript, analytics, tracking pixel, form, or external font in this page. The hosting provider may process ordinary web-request information under its own policies.

To update the policy, edit `index.html`, update its last-updated date, and commit to `main`. GitHub Pages deploys the site from the root of `main`.
